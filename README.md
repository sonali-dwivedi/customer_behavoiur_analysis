# 📊 Customer Behavior Analysis

A data analytics project to understand **customer purchasing behavior, revenue, discounts, subscriptions, products, and customer segments** using Python, SQL, and Power BI.

## 🛠️ Tech Stack

- 🐍 Python
- 📓 Jupyter Notebook
- 🗄️ PostgreSQL 
- 📊 Power BI
- 🐼 Pandas & NumPy

## 🔍 What I Analyzed

- 💰 Revenue by Gender
- 🛍️ Top Performing Products
- ⭐ Product Review Ratings
- 🚚 Shipping Type & Customer Spending
- 🎟️ Discount Usage
- 👥 Customer Segmentation
- 🔄 Repeat Buyers & Subscriptions
- 📈 Revenue by Age Group

## 📊 Dashboard

The interactive Power BI dashboard provides insights into:

**Customers | Average Spend | Reviews | Revenue | Sales | Age Groups | Categories | Subscriptions**
